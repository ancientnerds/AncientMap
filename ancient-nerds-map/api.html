Ancient Nerds Public API

A free, open REST API for archaeological data. Query more than 750,000 ancient sites aggregated from Pleiades, DARE, UNESCO World Heritage, Wikidata, OpenStreetMap, and a dozen further open databases — no API key required for read access.

  • Site search — full-text search with filters for country, category, period, and source
  • GeoJSON — coordinates and metadata for mapping applications
  • Archaeology news — curated discoveries and excavation updates
  • Research papers — open-access deep-research syntheses, licensed CC BY 4.0
  • Empires & polities — historical polity data based on the Seshat databank

Interactive documentation: Swagger UI · ReDoc. See also the research library, the site browser, and the interactive 3D globe.
