Wikidata Enrichment
Python scripts — HTTP only, no LLM

4-step pipeline fetching structured data from Wikidata and Wikipedia APIs, then importing into card_stats.

Phase 1
QID Reconciliation
Match sites → Wikidata entities via URL extraction, W3C Reconciliation API, SPARQL geo-search. Expect >80% match.
scripts/enrich_reconcile.py
Phase 2
Claims Fetch
Batch fetch P571 inception, P1435 heritage, P18 image, P17 country, sitelinks. 50 QIDs per request. Country QIDs resolved to labels.
scripts/enrich_fetch_claims.py
Phase 3
Wiki Article Selection
Pick best Wikipedia article per site. English preferred, multilingual fallback (de, fr, it, es…).
scripts/enrich_wiki_select.py
Phase 4
Import to card_stats
Upsert enrichment data (QID, confidence, heritage, inception, wiki URL, commons image) into card_stats table.
scripts/enrich_import.py

CLI Commands

# Full overnight run (~3-5 hours with images)
$ python scripts/audit_enrich.py --mode full

# Full run, skip image download (~1 hour)
$ python scripts/audit_enrich.py --mode full --skip-images

# Test with 3 random sites first
$ python scripts/audit_enrich.py --limit 3

# Test without image download
$ python scripts/audit_enrich.py --limit 3 --skip-images

# Use production API instead of local
$ python scripts/audit_enrich.py --api-url https://ancientnerds.com

# Individual phases
$ python scripts/audit_enrich.py --phase sync       # Fetch production → local DB
$ python scripts/audit_enrich.py --phase mechanical   # Wave 0 (+ country backfill)
$ python scripts/audit_enrich.py --phase enrich     # Wave 1 (+ card_stats import)
$ python scripts/audit_enrich.py --phase apply      # Apply enrichment → unified_sites
$ python scripts/audit_enrich.py --phase images     # Download wiki images (~2-4h)
$ python scripts/audit_enrich.py --phase verify     # Wave 2 prep
$ python scripts/audit_enrich.py --phase merge      # Apply agent results
$ python scripts/audit_enrich.py --phase package    # Export for db.html upload
$ python scripts/audit_enrich.py --phase export     # Re-export static JSON

Resumability — 3 Levels

Site-level
last_audited
Timestamp on unified_sites. Skip sites audited within 90 days unless --mode full.
Batch-level
merge_manifest.json
Tracks which agent batches are pending / in-progress / merged.
Phase-level
--phase flag
Re-run any individual phase independently without restarting everything.
