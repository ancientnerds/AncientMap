# Reading and researching a site record

[← Guide contents](README.md)

Select a marker or search result to open its site record. The amount of information varies because records come from different datasets and connected services.

## Record header

The header can contain:

- site name;
- category and period badges;
- source badge;
- alternate-source selector;
- like, bookmark, share, and related action buttons;
- window minimize, maximize, and close controls.

When alternate records have been matched, select the source badge to switch between them. Similar names do not guarantee that records describe the same place; compare coordinates and metadata.

## Location and coordinates

The location row shows the modern country and formatted coordinates.

- Use **Copy coordinates** to place the displayed location on the clipboard.
- Use **Search nearby sites** to create a proximity search centred on the record.

The embedded map provides satellite or map context and may offer Street View where supported. Its share action is for the map location; the site-header share action creates a link to the Ancient Nerds record.

## Description and metadata

The main text area can include:

- description;
- category and period metadata;
- original dataset fields;
- source attribution;
- Wikipedia or other reference links;
- numbered description citations.

Follow the original source and cited references before using a description as academic evidence. The aggregated record is an index and research aid, not a substitute for the source publication.

## Connected research tabs

The horizontal gallery has scroll arrows when all tabs do not fit. Counts appear as connected searches complete.

| Tab | Possible contents |
| --- | --- |
| **Photos** | Site and contextual images |
| **Videos** | Related video material |
| **Live** | Nearby public webcams |
| **3D** | Photogrammetry or 3D models |
| **Maps** | Historical or research maps |
| **Stories** | Ancient Nerds stories mentioning the site |
| **References** | Relevant external links |
| **Artifacts** | Museum or object records |
| **Books** | Related books or catalogues |
| **Papers** | Scholarly papers and research results |

Select the expand button beside the tabs for a larger gallery view. Some tabs require an internet connection and may not be available offline.

Connected results are automated discovery aids. The interface labels the gallery as beta because false positives are possible. Verify identity, date, location, authorship, and relevance in the linked item.

## Window management

Site records can be dragged and resized. A minimized record remains available in a compact bar. Multiple records may be selected for comparison; use Ctrl-click on Windows/Linux or Command-click on macOS where multi-selection is supported.

## Citation checklist

Before citing a mapped record:

1. Record the site title and Ancient Nerds record link.
2. Record the contributing source.
3. Open and cite the original source or publication when available.
4. Check coordinates against another authoritative reference.
5. Note whether chronology and category are exact, estimated, or broad.
6. Record the date you accessed the live data.
