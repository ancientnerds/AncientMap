Prompt Engineering

System Prompt — Separate Instruction from Input

Clean separation = cacheable, secure, 90% cheaper

✗ BEFORE
Everything mixed — every call fully paid
→
✓ AFTER
System cached — 90% cheaper

Lesson: Instructions in the system prompt, input in the user message — stable parts get cached, dynamic ones don't. Bonus: Trust boundary against prompt injection.
